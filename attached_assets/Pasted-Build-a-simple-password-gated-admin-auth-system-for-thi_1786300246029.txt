Build a simple password-gated admin auth system for this Next.js App Router project. No user accounts, no database involvement — just a single shared password stored in an environment variable.

1. Add two new env vars to .env.local.example (no real values):
   ADMIN_PASSWORD=
   ADMIN_SESSION_SECRET=

2. Create app/api/admin/login/route.ts:
   - POST handler that accepts { password } in the JSON body
   - Compares it to process.env.ADMIN_PASSWORD (exact string match)
   - On match: set an httpOnly, secure, sameSite=lax cookie named "admin_session" with the value of process.env.ADMIN_SESSION_SECRET, path "/", maxAge 7 days. Return 200.
   - On mismatch: return 401 with no cookie set.
   - On missing env vars at runtime: return 500, do not silently pass.

3. Create app/api/admin/logout/route.ts:
   - POST handler that clears the "admin_session" cookie. Return 200.

4. Create middleware.ts at the project root:
   - Runs on paths matching /admin/:path* and /api/admin/:path* (excluding /api/admin/login itself)
   - Reads the "admin_session" cookie
   - If its value doesn't exactly match process.env.ADMIN_SESSION_SECRET, redirect /admin/* requests to /admin (the login page) and return 401 JSON for /api/admin/* requests
   - If it matches, allow the request through

5. Update app/admin/page.tsx:
   - If not authenticated (no valid cookie — check this by attempting a lightweight authenticated fetch, or simpler: render a password form unconditionally and let middleware handle protection of any deeper /admin/* routes), show a simple centered password input + submit button that POSTs to /api/admin/login. On success, redirect to /admin/dashboard. On failure, show an inline error message.

6. Create app/admin/dashboard/page.tsx as a placeholder protected page (just an <h1>Admin Dashboard</h1>) — this route is what middleware should protect and is where Quotes/Reviews/Tracking sections will live later.

Do not build out any dashboard content, data fetching, or the Quotes/Reviews/Tracking sections yet — this prompt is auth plumbing only. Everything should build and run clean with zero TypeScript errors.
